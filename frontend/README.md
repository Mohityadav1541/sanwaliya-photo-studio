# Sanwaliya Photo Studio

Welcome to the Sanwaliya Photo Studio project. This application is a portfolio and booking system for wedding photography services.

## Project Info

**Website**: https://sanwaliyastudio.com

## Getting Started

To run this project locally:

1.  **Clone the repository**
2.  **Install dependencies**:
    ```sh
    npm install
    ```
3.  **Start the development server**:
    ```sh
    npm run dev
    ```

## Technologies Used

-   Vite
-   React
-   TypeScript
-   Tailwind CSS
-   shadcn/ui

## Deployment

This project is configured for deployment on Vercel.
